
# Reem's Personal Portfolio

## About the Project
A personal portfolio website showcasing my education,
technical skills, projects, and contact information.

## Features
- About Me and Education sections
- Technical skills with progress bars
- Project descriptions
- Downloadable resume
- Contact form connected to MongoDB
- Sage-green responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## How to Run
1. Install Node.js and MongoDB.
2. Install project dependencies using `npm install`.
3. Create a `.env` file with your MongoDB connection string.
4. Start the application using `npm start`.
5. Open http://localhost:3000.
